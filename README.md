# أكاديمية الأسرار — إرث العناصر

لعبة RPG سحرية بالعربية — تعمل offline، متوافقة مع الجوال، وقابلة للتحويل إلى APK.

## الميزات

- **6 عناصر سحرية**: النار، الماء، الجليد، الطبيعة، الظلال، الزمن — لكل عنصر 4 مهارات (مبتدئ → سيد).
- **15 اندماجًا**: دمج أي عنصرين يفتح تعويذة فريدة (بخار، لهب متجمد، نبض الحياة، صدع الزمن...).
- **قتال لحظي**: هجمات، شفاء، دروع، تفادي، تباطؤ، هروب.
- **أكاديمية تفاعلية**: 6 معلمين، تعلم عناصر جديدة بـ 100 ذهب.
- **تقدم الشخصية**: مستوى، XP، ذهب، نقاط مهارة.
- **نظام مهام**: رئيسية، جانبية، استكشاف، شروط فتح متسلسلة.
- **خريطة عالم**: 7 مناطق مقفلة تدريجيًا حسب المستوى.
- **حفظ تلقائي**: localStorage مع تحقق من صحة البيانات.

## المتطلبات

- متصفح حديث (Chrome، Firefox، Safari).
- Node.js 20+ (لبناء APK فقط).
